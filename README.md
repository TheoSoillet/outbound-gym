
# OutboundGym

A reinforcement learning environment for
training tool-using LLM agents on B2B
prospecting tasks.

## Research Question

Can reinforcement learning improve the
tool-use efficiency and task success rate
of small language models?

## Initial Environment

An agent must identify qualified companies
from a simulated CRM using limited tools
and a fixed research budget.

## Planned Experiments

1. Baseline model evaluation
2. Supervised fine-tuning (SFT)
3. Reinforcement learning (RL)
4. Generalization and cost evaluation

## Tech Stack

Python, PyTorch, TRL, verl
